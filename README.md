# THF — The House of Fitness — Premium Website Prototype

Built from the supplied THF brief. The brief establishes the THF identity around the uploaded artwork: THF monogram, wing + dumbbell visual language, black/charcoal, metallic silver, burnt orange/copper, industrial luxury, athletic typography and dramatic lighting.

## Included
- Dark industrial-luxury landing page
- Sticky navigation and mobile CTA
- Cinematic hero: “WHERE STRENGTH TAKES FLIGHT.”
- Brand statement
- Why THF / four pillars
- Six programs
- THF experience
- Transformation placeholders
- Editable trainer placeholders
- Membership options without fabricated pricing
- Free-trial form with success state
- Lucknow / SGPGI / Ansal API / Sushant Golf City SEO copy
- Gallery placeholders
- Instagram @thf.thehouseoffitness
- Location / Google Maps placeholder
- Final CTA and footer
- Responsive mobile layout
- Print-friendly CSS

## Important
The prototype deliberately does NOT invent trainer names, certifications, awards, member counts, testimonials, pricing, exact address, opening hours, equipment brands or transformation results.
